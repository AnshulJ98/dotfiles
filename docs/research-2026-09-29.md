**Implementation:** Sonnet 5.5 at medium scored 38.5 against Opus's 42.7 at under a third of the cost (Bito). Opus only wins where it has to reason about undocumented behavior.

**Review:** on 13 hard known-bug cases (CodeRabbit), Sonnet 5.5 caught 6, Opus 5.5 standard caught 8 and Opus max caught 10. Separately, one tester found Opus 5.5 at *low* effort caught 72% of known bugs against 56% for Opus 5 at high.

**Effort:**
- Medium is the default. High costs about 1.3x for a small gain.
- Avoid max: Sonnet 5.5 at max *lost* FrontierCode points by fanning out to subagents and making out-of-scope edits.
- High costs about a third more for the same completion rate, and it drifts out of scope more often.

**Community consensus:** Opus plans, Sonnet implements, Haiku 5.5 for fixes when it ships, Fable only when you are stuck. This matches our plan.

**Prompting (Anthropic Opus 5.5 guide):**
- Hand over the whole task and name the finish line.
- Delete "think carefully." For a quick reply, say "Answer directly."
- Add a stop rule: keep going when no input is needed; stop only when blocked or before anything destructive.
- Keep the task list in a file.
- End with Blocked on me / Changed / Found. Read "Blocked on me" first.
- "Mark anything you couldn't confirm, and say where you looked."
- Run a model review pass before the human one.
- Don't ask the model to show its reasoning; it can be refused.

**`/doctor prompt-audit` patterns it flags:**
- pressure words (CRITICAL, MUST)
- prohibition lists
- step scripts for judgment calls
- incident history

Our fragments are heavy on "Never …" lists. The guide warns that banning a mistake the model wasn't going to make can pull it toward that mistake. Run the audit on the generated `CLAUDE.md` and apply the findings to the fragments, not the output.

## pi 0.99

- **Virtual models:** skip. Every model switch loses the cache; separate processes already handle phase changes.
- **Codemode:** try it for a week in the main session. It collapses multi-tool steps into one request. Enable with `"defaultTools": ["+codemode"]`.
- **MCP / `tool_search`:** built-in extensions `builtin:mcp`, `builtin:codemode`, `builtin:tool-search`, `builtin:llama.cpp`. Scout's `-ne` already disables them. Turn off `builtin:mcp` and `builtin:llama.cpp` in the main session with `-builtin:<name>`.
- **Classifiers / Jev:** skip. Community reaction is "Pi is becoming bloated."

## Ecosystem

- **pi-review:** `/review` on a stripped branch with P0–P3 findings, and `/review-back` returns you to your session. Use it as the model review pass before `review-branch.sh`, run on Opus.
- **pi-ralph-loop:** copy its guards into `worker-sensors.ts`; don't install it.
  - block `write`/`edit` outside `files-allowed`
  - block `git push|reset|clean` and `rm -rf`
  - rerun the tests after the model says it's done
  - "can't run here" stops the run; "failed" retries once
- **codex-pi:** confirms `slice-loop`, and adds two ideas:
  - require a clean checkout before a run
  - write a review packet per run (contract, patch, test output, `usage.json`)
- **pi-subagents, pi-intercom, oh-my-pi:** skip. They are in-process fan-out, and a zazencodes demo found 10 subagents cost 300k tokens where 4 would have done.
- **Claude Code `/goal`, dynamic workflows, ultracode:** skip. Ultracode runs over 1.7M tokens are reported, and this is the unattended orchestration the 08-28 bench rejected.
