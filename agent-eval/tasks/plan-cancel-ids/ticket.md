Two problems with cancelling in booking/. Cancelling one booking sometimes removes other bookings as well; I think the DELETE handler ends up calling cancel more than once. And ids like `01`, `1.0`, `1e0` or `0x1` cancel booking 1: only the canonical decimal id should match; anything else, including a path with extra segments such as `/bookings/1/extra`, is a 404 and the booking stays.
